# RockClan Records v2 (시안)

락클랜 전적·랭킹 사이트 개편 시안입니다. 클랜원 피드백을 받아 고쳐 나가는 용도입니다.

- 경기 기록: 기존 사이트의 공식 DB를 **읽기 전용**으로 실시간 사용 (공식 기록은 바뀌지 않음)
- 결과 제출·의견 게시판: 별도 Supabase 프로젝트(`config.js`의 WRITE_*)에 저장
- 빌드 없음 — 정적 파일 그대로 GitHub Pages에 올리면 동작

## 화면
| 경로 | 내용 |
|---|---|
| `#/ranking` | 랭킹 (레이팅 v2 / 기존 ELO 비교, 정렬, 표본 필터, 내 위치, 시즌 하이라이트) |
| `#/matches` | 경기 기록 (날짜별, 세트별 승리 확률·변동, 이변·중복 의심 표시) |
| `#/player?id=` | 선수 프로필 (레이팅 추이, 종족·맵·파트너·라이벌, 승리 확률 계산기) |
| `#/analysis?a=&b=` | 전력 분석 (맞대결, 스카우팅 포인트, 티어 구간 승률표) |
| `#/submit` | 결과 제출 · 상대 팀 확인 (48시간 무응답 시 자동 반영) |
| `#/board` | 의견 게시판 (공감, 댓글) |
| `#/guide` | 레이팅 안내 · 시뮬레이터 |

## 설정
`config.js`에서 시즌, 레이팅 파라미터(`V2`), 랭킹 등록 조건(`ELIGIBLE`)을 바꿀 수 있습니다.
쓰기 저장소 테이블은 `supabase.sql`을 Supabase SQL Editor에서 한 번 실행해 만듭니다.

## 운영 메모
- 의견 상태(접수/검토중/반영예정/반영완료)는 Supabase 대시보드 → Table Editor → `feedback_posts.status`에서 변경
- 잘못된 제출은 `submissions.status`를 `canceled`로 변경
- 시안 단계라 로그인 없이 "내 선수" 선택(신뢰 기반)으로 운영
